# Experimental Data

Store raw measurements in `raw/`.

Store cleaned/processed datasets in `processed/`.

Recommended fields:

- timestamp
- test_id
- flow_rate
- water_temperature
- ambient_temperature
- humidity
- pump_voltage
- pump_current
- generator_voltage
- generator_current
- piezo_voltage
- piezo_current
- water_level
- pH
- turbidity
- TDS
- conductivity
