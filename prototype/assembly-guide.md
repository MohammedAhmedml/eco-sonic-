# Prototype Assembly Guide

## Phase 1 — Base

1. Cut and prepare the MDF/plywood base.
2. Add rubber feet.
3. Mark locations for tanks, pump, water wheel, electronics, and treatment modules.
4. Install aluminium structural supports.

## Phase 2 — Water System

1. Mount transparent reservoirs.
2. Install bulkhead connectors with appropriate seals.
3. Connect tubing using compatible fittings.
4. Add valves and check valves.
5. Install the pump with rubber isolation mounts.
6. Add the water wheel and generator housing.
7. Perform a water-only leak test before installing electronics.

## Phase 3 — Treatment

Install only the treatment stages required for the selected experiment.

Verify flow direction and accessibility for maintenance.

## Phase 4 — Energy Harvesting

Mount the water wheel and generator securely.

Connect generator output to the rectifier and measurement/conditioning circuit.

Install piezoelectric elements on the vibration structure.

## Phase 5 — Electronics

1. Mount the ESP32.
2. Connect sensors using verified pin assignments.
3. Add display and indicators.
4. Install pump/fan drivers.
5. Add fuse and emergency cutoff.
6. Keep electronics physically separated from wet sections.

## Phase 6 — Testing

1. Test electronics without water.
2. Test sensors individually.
3. Test plumbing without electronics.
4. Test pump circulation.
5. Measure generator output.
6. Test vibration harvesting.
7. Integrate subsystems.
8. Record results.

Never power wet electronics before inspecting the entire system for leaks.
